# API reference

The public interface of JacoPy, grouped by topic. Names importable from the top-level
`jacopy` package are stable; the subpackage facades (`jacopy.packages.*`,
`jacopy.research`) are public but still evolving. Any other module path and every name
that starts with an underscore is internal.

