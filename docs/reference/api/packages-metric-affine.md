# Metric-affine geometry

Connections, torsion, curvature and non-metricity, Ricci and Einstein tensors, the Bianchi identities, the Cartan structure equations and the Koszul formula, on the tangent bundle and on an algebroid. Here `Metric` and `metric` are the package's metric context, not the metric atom exported by `jacopy`. The names below form the public facade `jacopy.packages.metric_affine` (its `__all__`); the facade is public but still evolving.
