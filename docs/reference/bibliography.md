# Bibliography

This page lists the works JacoPy cites, in APA 7 format. The entries are
generated by the library's own renderer from the reference table in
`jacopy/bibliography.py`, so they are exactly what JacoPy prints under a
proof (for example in `theorem_to_latex_document(..., references="apa")`).
A field that none of the available sources provides is printed as
"[… not in source]" rather than guessed.

## Notes on individual sources

* **Kosmann-Schwarzbach (2004).** The code cites a derived-bracket
  source as "Kosmann-Schwarzbach 1996"; the bibliography lists the 2004
  paper "Derived brackets", and it is not certain that this is the work
  meant.
* **Asakawa, Muraki, Sasa and Watamura (2015).** The equation and
  section numbers that the code cites from this paper have not been
  verified.
* **"The E6 paper".** Some code comments (in
  `central/objects/multivector_interior.py`, `research/block_matrix.py`,
  `packages/drinfeld/examples.py` and
  `packages/generalized/exceptional_double.py`,
  `exceptional_rotation.py`, `frame_evaluation.py`) and notebooks cite equations
  (4.10)–(4.15) of a source referred to as "the E6 paper". Its
  bibliographic data has not yet been identified, so it has no entry
  above; these equation numbers are not those of Çatal-Özer, Doğan and
  Yetişmişoğlu (2025).

from jacopy.bibliography import apa_reference, bibtex_entry

print(bibtex_entry("DereliDogan2023"))
