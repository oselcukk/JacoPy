# How-to guides

These guides show how to write the mathematics you already know in JacoPy: how to define
objects, how to write operations, operators and brackets, how to ask for a proof and read
the result, and how to use the geometry packages and the research interface. Each page
pairs mathematical notation with the code that expresses it, the types of the arguments and
the type of the result. Every code example on these pages is executed when the
documentation is checked, and every output shown comes from a real run.

Start with [Syntax at a glance](syntax-at-a-glance.md) for a one-page summary. The
[API reference](../reference/index.md) documents each function in detail.
