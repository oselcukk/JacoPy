# jacopy has no required runtime dependencies; the optional ones are
# declared once, as extras, in pyproject.toml:
#
#   rich    coloured terminal display (jacopy.display.terminal)
#   oracle  sympy, for the model oracle (jacopy.oracle, pytest --oracle=…)
#   test    pytest
#   docs    ipykernel, the Jupyter kernel for examples/*.ipynb
#   dev     all of the above
#
# This file is a one-line shortcut for a development install from a
# clone (`pip install -r requirements.txt`, run in the repository root):
-e .[dev]
