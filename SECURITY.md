# Security Policy

## Supported versions

JacoPy is in alpha. Security fixes are made only for the latest
release and for the `main` branch.

| Version | Supported |
|---|---|
| 0.1.x (latest pre-release) | yes |
| older versions | no |

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues,
discussions or pull requests.

Report them privately through GitHub:
open the repository's **Security** tab and choose
**Report a vulnerability**
(https://github.com/oselcukk/JacoPy/security/advisories/new).

Please include a description of the problem, the steps to reproduce it,
the affected version, and its possible impact. You can expect an
acknowledgment within seven days. Once the problem is confirmed, a fix
is prepared and released, and the report is credited unless you prefer
otherwise.
